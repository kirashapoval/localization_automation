# Book Translator - Figma Plugin

Плагин для перевода книжного контента в Figma с автоматической адаптацией текстовых блоков.

## Возможности

- **Перевод на 20+ языков** через Google Gemini API
- **Автоматическая адаптация текста** при увеличении объёма после перевода
- **Работа с Text Styles** — изменения применяются глобально ко всей книге
- **4-шаговый алгоритм адаптации:**
  1. Увеличение ширины текстового поля (если позволяет контейнер)
  2. Уменьшение отступов между блоками
  3. Уменьшение межстрочного интервала
  4. Уменьшение размера шрифта (последний вариант)

## Установка

### 1. Установка в Figma

1. Откройте Figma Desktop
2. Перейдите в `Plugins` → `Development` → `Import plugin from manifest...`
3. Выберите файл `manifest.json` из папки `figma-translator-plugin`

### 2. Получение API Key

1. Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Создайте новый API key
3. Скопируйте ключ для использования в плагине

## Использование

### Подготовка

1. **Создайте Text Styles в Figma:**
   - `Heading 1` — для главных заголовков
   - `Heading 2` — для подзаголовков
   - `Body` — для основного текста
   - `Caption` — для подписей

2. **Привяжите текстовые блоки к стилям:**
   - Выберите текст
   - В панели справа нажмите на иконку стиля текста
   - Выберите или создайте нужный стиль

### Перевод

1. Выберите все фреймы книги (страницы)
2. Запустите плагин: `Plugins` → `Book Translator`
3. Введите ваш Gemini API Key
4. Выберите целевой язык
5. Нажмите **Analyze** для preview изменений
6. Проверьте предлагаемые адаптации
7. Нажмите **Apply Changes** для применения

## Логика работы

### Глобальное применение изменений

Если хотя бы одна страница требует уменьшения шрифта, это изменение применяется ко **всем страницам книги** для сохранения консистентности.

Пример:
- Страница 15: текст увеличился на 20% → нужно -1pt
- Страница 45: текст увеличился на 30% → нужно -2pt
- **Результат:** -2pt применяется ко ВСЕМ страницам

### Адаптация по стилям

Каждый Text Style адаптируется независимо:
- `Heading 1` может получить -2pt
- `Body` может получить -1pt
- `Caption` может не измениться

## Troubleshooting

### "No frames selected"
Выберите фреймы страниц книги перед запуском плагина.

### "API error: 400"
Проверьте правильность API key и наличие квоты в Google AI Studio.

### Текст не переводится
Убедитесь, что:
- Текстовый слой не заблокирован
- Шрифт доступен в системе
- Текст не является частью компонента с ограниченными правами
